mode 3 仅可作为 `switching:true` 的旧 ENG1 阻塞诊断被读取，网页禁止 Note、RAW、引擎音色／CC／FM 参数和 `SELECT 3`；用户仍能显式切回 0/1/2。独立确认且可用的全局 RVR1 混响仍沿用原控制 gate。没有保留加法运行描述或 patch 请求路径。
