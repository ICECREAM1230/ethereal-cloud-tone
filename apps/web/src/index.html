“已接收”表示 HTTP 请求进入事件总线；“已采用”表示 ESP32 控制任务采用。MIDI 排队回执仅表示请求已入队，不代表 FPGA 已解析、采用或已经发声。计数属于当前网页绑定；重新绑定后从空按键确认开始，旧上下文的结果不能确认新输入。FPGA 最近 accepted / completed / result 保留原 session / epoch / sequence，与 HTTP 序号无逐条映射。参数显示 owner 完成缓存，不是芯片寄存器读回。实际声音需设备确认。
