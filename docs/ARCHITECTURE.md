# 空灵云音架构导读

本架构说明以当前源码、Gowin工程清单和接口实现为依据。图示用于说明职责与数据流，实际硬件连线按约束、板卡与接线核实，不根据示意图推断新的引脚分配。

- [项目介绍](PROJECT_OVERVIEW.md)：定位、声音路线、工程组成和使用顺序。
- [整体系统架构](SYSTEM_ARCHITECTURE.md)：FPGA/AE350、ESP32 A/B、手机端及主机工具的分工与通信。
- [FPGA内部架构](FPGA_ARCHITECTURE.md)：活动顶层、声音引擎、时钟域、PCM输出、IP和初始化数据。
- [发布检查与已知边界](VALIDATION.md)：本次实际通过、失配和未执行的验证。

阅读建议：先看系统图，确定正在修改的是界面、通信、声音控制还是音频数据通路，再进入对应源码入口。默认启用项以 `.gprj`和顶层参数为准；存在某个源码目录不代表它正在当前生产配置中运行。
