# ESP32 激光竖琴：EC11 与 GPIO 连接说明

2026-10-30。按用户本次打开的嘉立创 EDA「1激光竖琴」→「光敏电阻原理图」→「排插」页核对。文档以 ESP32 GPIO 代号为主，排插针号作为追踪依据保留。

**更正：光敏输入和编码器都按用户提供的 J1/J2 引脚图、用同一排插对应关系换算后，没有 GPIO 重叠。此前“六项重叠”的表述混用了光敏原图 IO 文字和编码器排插换算两个依据，现撤回，不作为硬件冲突结论。**

四组编码器 A/B/按压仍分别对应 GPIO13/14/12、GPIO40/39/41、GPIO47/21/38、GPIO2/42/1。用户随后逐项提供了十二条编码器GPIO，并明确将误读的 ENC_A4=GPIO12 更正为 ENC_A4=GPIO2；十二项全部与本次核对结果一致。十二个编码器 GPIO 互不重复，也不占 GPIO19/20。原图十个 IO 标签与开发板参考图同号针位的差异保留供修图核对，不等于电路实际共用 GPIO。

## 对照依据与方向

- 本页 H1/H2 的符号实际各有 22 针。
- 原图 H1.2 接 +3.3V，与参考图 J1.1/J1.2 的 VDD33 端对应；J1 的另一端为 5V/GND。按用户要求以供电端与 GND 端校准，采用 H1→J1、H2→J2 同号对应，不按屏幕左右或翻面观察自行倒序。
- 参考图 J2 的 1 针和 21/22 针为 GND，2/3 针为 U0TXD/U0RXD；编码器3的 H2.17/H2.18 对应 GPIO47/GPIO21，USB GPIO20/GPIO19 则在 J2.19/J2.20。
- GPIO 换算依据是用户提供的开发板引脚图；编码器到 H1/H2 的连线依据是本次实际读取的原理图，并以 PCB 中对应排插焊盘与串联电阻输出网交叉核对。未测量实物导通或确认连接器装配朝向。
