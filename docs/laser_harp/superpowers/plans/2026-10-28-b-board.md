# B 板激光竖琴固件实现计划

> 用户已明确要求在本会话开始编写，采用当前独立仓库直接执行；不暂存、不提交，不修改 A 板、FPGA 或 CAD。

**Goal:** B 板 ESP32-S3 将十二路激光及四个 EC11 转为 MIDI，通过原生 USB 或标准 BLE MIDI 向 A 板输出。

**Architecture:** 可在主机测试的输入/音乐状态核心；一个状态机拥有输入和设置；USB 与 BLE 各自维护发送成功后的音符状态。拥塞时重试，连接换代重置并重放当前状态；AUTO 优先 USB，释放旧路由后再切换。

**Tech Stack:** ESP-IDF v6.1，本机版本匹配的 NimBLE 与 esp_tinyusb 2.4.0，C11 主机回归，UART/CH343 控制台。

**Spec:** 用户本会话的 A/B 职责、USB MIDI/BLE MIDI 和四编码器要求；`docs/hardware-wiring.md` 的用户确认 IOxx=GPIOxx。

## 约束与选择

- A 板现有工程只读参考：标准 BLE MIDI service/characteristic、名称 FPGA_Bluetooth、断连清理语义。B 板不是原主工程 ESP32。
- 激光 GPIO 固定为 4,5,6,7,15,16,1,2,42,41,40,39，默认音符 C4–B4、通道 1；按完整遮光时长 20–500 ms 映射力度 16–127，恢复光照后发声，gate 默认 200 ms；输入有效电平可配置，提供原始电平诊断。
- 编码器 MCU GPIO 未在已读文件中建立可靠对应，使用显式未配置值 -1，支持 Kconfig 与 UART 控制台绑定，不猜测原排针号。实现全部解码/功能并阻止 GPIO 冲突；不声称未绑定编码器已实机可用。
- 编码器 1/2/3/4：半音移调/CC7 音量/CC74 截止/CC71 共振；按键 1/2：±1 cent 微调，按键 3：滤波复位，按键 4：Panic。EC11 默认每 detent 2 个合法边沿，可选 4。
- 1 ms 软件扫描；激光 2 ms 稳定确认，按键 20 ms；启动及 Panic 后须先看到未触发状态再接受触发。
- 微调发送 Pitch Bend，默认按接收端 ±2 半音换算，文档明确该假设。
- 默认仅为构建采用保守 4 MB Flash 兼容配置，不启用 PSRAM/OTA；不能把构建配置当作 B 板实物规格。没有烧录授权。

## Review Focus

1. 已发送 Note On 后的拥塞、断连、移调和 Panic 不产生卡音。
2. 队列中的异步 BLE 写不得跨连接 epoch 落到新会话；发送确认必须匹配同一 MIDI 消息。
3. AUTO 的双链路可用情况不会持续重复触发。
4. 机械抖动、反转、非法 AB 跳变、时间戳回绕及启动遮挡行为可重复验证。
5. 不复用 A 板引脚/固件，不将未知编码器引脚误配置成 USB、激光、Flash/PSRAM 或 console GPIO。
