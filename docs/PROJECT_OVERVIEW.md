# 空灵云音：项目介绍

空灵云音（Ethereal Cloud Tone）是一套面向电子音乐演奏与实验的 FPGA 合成器系统。工程以 Tang Mega 138K 上的高云 GW5AST FPGA 和 AE350 处理器为核心，将声音合成、MIDI与传感器控制、无线交互、手机应用和电脑调试工具组织成一套可阅读、可构建、可验证的源码工程。

项目采用硬件和软件分工：FPGA承担声音计算、音频数据通路与外设接口；AE350参与声音控制和传感器处理；ESP32-S3提供无线控制、MIDI以及配套输入。使用者可以通过手机网页、Android应用或MIDI设备调整音色，也可以使用激光竖琴、FDC传感器等输入进行演奏与实验。实际连线和启用组合以对应工程配置和硬件为准。

## 声音与交互

核心声音路线包括三类：

- **减法合成器**：由振荡器生成基础波形，结合包络、滤波和调制塑造音色。DDS是振荡器的实现技术，不是整条声音路线的名称。
- **KS物理建模**：以延迟反馈结构实现拨弦类声音，相关模板、控制、音色处理与数据通路随工程保存。
- **FM合成器**：基于JT51的FM声音路线，保留其独立接口、时钟与第三方许可边界。

控制侧将演奏输入与音色参数分开处理：MIDI事件承担音符和演奏控制，模板及配置接口承担参数更新。网页和Android应用提供操作界面，主机工具用于连接诊断、PCM采集、协议检查和测量。具体参数、路由和背压机制见[系统架构](SYSTEM_ARCHITECTURE.md)与[FPGA架构](FPGA_ARCHITECTURE.md)。

## 技术组织方式

**硬件加软件的控制边界。** 处理器与控制器将演奏意图转换成声音引擎可消费的事件和参数；RTL负责对应的数据通路与音频输出。接口合同和实际C/Java消息互操作测试用于约束两侧的理解。

**多声音路线的集成。** 三种核心引擎共享项目的控制和输出体系，同时保留各自的时钟、运行时和专项验证边界。跨时钟传输、队列、确认和背压由实际实现定义，不通过把所有模块视为同一时钟来简化。

**从控制界面到测量工具。** 手机端用于演奏和调音，电脑端用于观察协议与PCM，测量代码用于检查采集和解码。软件测试、厂商实现工具和实物测量记录各自说明能证明的范围。

**可追溯的工程输入。** Gowin `.gprj`是FPGA器件、文件顺序和启用状态的入口。AE350程序镜像与IP内嵌ITCM进行字节核验；客户端合同记录准确来源身份，修改后重新计算实际内容绑定。

## 适合如何使用

先阅读[总架构索引](ARCHITECTURE.md)，再按需要进入FPGA、A/B板或客户端目录。只读完整性检查为 `python3 -B tools/verify_project.py`；实际构建需要本机准备相应的Gowin、ESP-IDF、JDK/Android SDK、Node或Python环境。

可以将本工程用于理解硬件合成器、研究多种合成路线、调试MIDI/传感器控制，或继续扩展手机界面与测量工具。修改时应保持当前源文件与初始化镜像、协议合同和对应验证结果之间的关系。
