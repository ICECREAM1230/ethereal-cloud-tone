- 无线方案候选为激光竖琴 S3 充当 BLE MIDI central，向现有 `FPGA_Bluetooth` MIDI 服务写入事件；这属于待落实方案，不表示对实物连通性或延迟已经验收。
- 控件功能提案：ENC1 音高移调，ENC2 CC7 音量，ENC3 CC74 截止频率，ENC4 CC71 共振；前两个按键用作微调降低/升高。音高微调需明确 MIDI Pitch Bend 的接收端范围；不能把 FPGA 音源内部参数和 MIDI 标准编号直接等同。
