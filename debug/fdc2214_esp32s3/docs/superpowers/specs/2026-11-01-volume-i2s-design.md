# ESP32 音量标定与四线 I²S 测试

用户要求修改独立ESP32程序，稍后用于标定特雷门琴音量，并引出简单四线I²S。继续在当前ESP32-S3工程实现，不改FPGA/AE350主工程、不烧录设备。已有接线SCL8/SDA18/ADDR17/INT16/SD4，外部40MHz和3.3V上拉保持。

实现选择：CH1默认控制音量，可选择CH0..3；固定440Hz测试音将音高与音量排障分开。四线解释为MCLK15/BCLK5/LRCLK6/DOUT7，均可配置；GND另接。48kHz、Philips I²S、16位样本/32位双声道槽，MCLK=256Fs、BCLK=64Fs。需外接兼容I²S DAC；不配置未知codec寄存器，不假装ESP32-S3有模拟音频输出。

纯C组件负责新鲜度/WD/硬错误筛选、允许并标记AW、三点中值、固定端点归一化、30ms低通、线性或平方曲线、超时静音、128个新鲜样本中值端点标定、配置校验、命令解析及限幅/渐变正弦PCM。标定有5秒截止，双端点成组应用，失败保留现用参数。默认端点沿用历史临时CH1值，未经用户现场标定不称为正式范围。

RTOS适配：唯一I²C采集任务只向单槽覆盖队列提交原始帧；10ms标定任务拥有状态和命令队列；独立I²S任务写DMA，不在采集/音频任务打印串口。原sample/range CSV不变，额外volume记录可由原GUI忽略。串口命令audio/vol支持reference/sensor/off、数字电平、频率、通道、capture loud/mute、range、curve、apply、export。启动PCM为0，reference明确绕过传感器用于核对下游增益；参数仅RAM，导出供AE350使用。

验收：纯C严格编译与ASan/UBSan、真实行为测试（端点反向、低增益、采集稳健性/超时、AW/WD、原码新鲜度、坏参数拒绝、PCM频率/双声道/限幅/淡出）；原驱动和CSV/GUI回归使用新结果目录，保护旧固定报告；ESP-IDF6.1实际构建音频开/关。当前未指定DAC型号/接线完成，因此不进行外部DAC音质或实板验证。Context7没有6.1索引，API和槽宽/WS依据本机6.1官方源码/文档核对。
