# KS／FM 历史实测资料（2026-11-02）

本目录保存 **2026-11-02 的历史实验**：KS 拨弦和默认 FM 音色的十段板上录音、原始传输数据、MIDI 事件及回执、离线分析、报告图稿和当时相关代码。资料来自冻结 ZIP 的 606 个普通文件，本次没有重新采集、分析、仿真、综合、布局布线或编程硬件。

这组历史记录不代表当前 `main` 的 FPGA 位流、固件或新硬件验收。旧报告中的“当前”、构建成功、板上状态、SHA 和用户码，均按 **2026-11-02 当时的版本** 理解。历史 FPGA 位流 SHA256 为 `02e62fe1280fc406f992620120e662bba3d8f4c279ba6fcce7ac0cc4558cfed3`，记录的用户码为 `0x00006A5B`。它们不能用于断言现仓库代码已经生成或加载了相同位流。

## 测量内容和边界

基础 KS 使用 Legacy KS 配置，保留 3000 ms decay 参数；不覆盖 Harp／Guzheng 物理音色。FM 为当时启动默认的单算子音色，不覆盖复杂多算子调制。力度为 100，PCM-B 为 SUM，混响 wet／damp 为 0。历史报告基于 96008 Hz 的名义采样率标签，采样时钟未独立校准。

满复音的 16／8 是发送的 MIDI 同时音符请求数，并非直接读回的 native active voice 计数；HTTP dispatch 时刻也不是 native 采样标签。传输 v1 没有 CRC、native sample index 或 FPGA 内部丢样计数。原报告没有匹配整段 KS／FM 仿真 WAV，不能据此宣称 RTL 逐样本一致。

`02_代码` 保存历史采集／离线分析工具、共享依赖、PC 接收分析包、KS／FM／JT51 实现参考、AE350 和配套 ESP32 控制代码。共享文件中的 `sub`、`upstream` 等名称按原实验依赖保留；这不增加其它合成器的实验成果，也不构成一套可直接独立综合的完整 FPGA 工程。当前正式工程入口仍是仓库根目录下的 `fpga/ethereal_cloud_tone.gprj`。
