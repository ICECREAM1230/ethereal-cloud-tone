# 离线复现入口

以下入口只读取已归档的数据，不访问FPGA、ESP32、CH569、网络或硬件共享锁。原始采集和共享烧录代码仅供追溯，不由本入口运行。

在解压目录中运行：

```bash
python3 -B '06_离线复现/离线入口.py' verify
python3 -B '06_离线复现/离线入口.py' analyze-basic --out '/另一个新目录/基础重分析'
python3 -B '06_离线复现/离线入口.py' analyze-poly --out '/另一个新目录/满复音重分析'
python3 -B '06_离线复现/离线入口.py' figures --out '/另一个新目录/重新导图'
```

`verify`只用Python标准库。重分析需要NumPy；基础分析和图稿导出另需PySide6 Essentials、pyqtgraph及所列字体。版本见`05_版本与校验/运行环境.json`。输出必须使用新目录，原始数据目录禁止作为输出位置。

基础分析会重新核对8段RAW/payload/WAV、通道与事件记录，计算音高、幅度、释放窗和频谱；满复音分析核对另外2段和各3轮触发。图稿导出仍使用原录音，生成12张中文图，不使用任何模拟或替代音频。

新入口只重定位原分析器的数据根目录与PC代码路径，原脚本本身保持逐字一致。它不把部分实现参考变成完整可编译FPGA工程，也不自动安装包、改固件或编程设备。
