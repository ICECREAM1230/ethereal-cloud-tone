# FPGA 合成器术语

本词汇表统一音源、信号发生模块与演奏控制的称呼。2026-10-18 按用户确认及现有代码校正。

## 术语

**减法合成器**：
项目原有的完整音源：以振荡器产生波形，经滤波塑造频谱，由包络、调制与增益控制声音动态。
_避免_：将整套音源称为“DDS 合成器”或将其与 DDS 振荡器等同。

**DDS 振荡器**：
减法合成器中的信号发生部分，通过相位推进与相位到幅度转换产生波形。
_避免_：用 DDS 单独指代滤波、包络、混音在内的完整合成方式。

**DDS 模式（历史兼容名称）**：
现有工程与控制接口中对原减法合成器模式的名称。文档中的“DDS/KS/FM”分别表示减法合成器、KS 物理建模合成器和 FM 合成器。

**合成元素**：
可独立配置音高、波形、滤波和增益的声音单元；多个元素可以组成一个演奏声部。

**演奏声部**：
具有独立音符与启停生命周期的演奏单位，可以包含多个合成元素。
