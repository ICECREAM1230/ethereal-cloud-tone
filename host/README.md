# Host tools

- [b_board_debugger](b_board_debugger/README.md)：B 板 Tk 调试与网页监控；从归档根目录以 `python3 -m host.b_board_debugger --demo` 查看离线界面。
- [pcm_capture](pcm_capture/README.md)：当前 Qt USB PCM 采集程序，需要自建本地 `.venv` 和 requirements.txt 所列依赖。
- [pcm_measurement_reference](pcm_measurement_reference/README.md)：另一维护线的独立音频测量代码；不混用两套协议实现。
- [FDC GUI](../debug/fdc2214_esp32s3/README.md)：独立 FDC 原始数据与标定界面。

本次归档未启动任何连接实物的服务。
