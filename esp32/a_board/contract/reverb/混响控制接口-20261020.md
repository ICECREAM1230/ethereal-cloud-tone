# 混响控制契约 v1（2026-10-20）

**状态：FPGA 待实现。本文定义新增接口，不表示当前源码、位流或设备已有 SPI 混响控制。**

C常量定义见 `../../main/reverb_control_contract.h`，与公开API一同位于组件内，保证只复制main/的隔离构建也包含完整输入。

适用现有 `reverb_audio_bank` 的16位无符号Q15输入：wet为0..32768，damp为0..28672。FPGA编译期默认值目前均为8192；固件不能把这些默认值当成当前硬件读回，更不能在未识别能力时写入下面的拟定地址。

## 地址与最小语义

以下为32位SPI字地址。现有SPI将整个07xx读写转到midi读写接口；已核对RAW 0700..070A、ENG1 070B..0710及FM验证07F0..07FA，0720..0727在当前映射中未分配。FPGA负责人后续需实现单独解码，不更改现有RAW命令。

| 地址 | 方向 | 契约 |
|---|---|---|
| 0720 | RO | magic `0x52565231`，ASCII `RVR1` |
| 0721 | RO | ABI `0x00010000`，本版固件只接受该版本 |
| 0722 | RO | bit0控制接口READY、bit1事务BUSY、bit2FAULT，其余0；READY不是音频健康证明 |
| 0723 | RO | 实际控制参数对：wet[31:16]、damp[15:0] |
| 0724 | RO | 最近已应用COMMIT序号；启动0，主机使用1..0x7fffffff，到上限回到1 |
| 0725 | WO | shadow参数对，与0723相同布局；合法完整写入置内部shadow_valid，不直接改变活动参数 |
| 0726 | WO | COMMIT序号；READY、无BUSY/FAULT且shadow_valid时原子捕获完整shadow和序号，并消费shadow_valid |
| 0727 | RO | status generation；0722..0724有变化时更新，允许32位自然回绕 |

非法范围、0/高位序号、FAULT/BUSY期间或没有有效shadow的COMMIT不得修改参数或伪造成功。单一SPI owner保证本版没有并行控制写入；重复的同序号/同载荷可基于已捕获身份返回原确认，不重新应用，同序号不同载荷不得接受。复位须取消旧mailbox，不可恢复时重播旧事务，并清BUSY、applied sequence及shadow_valid为0。只有本次启动收到合法完整shadow写入才能重新置shadow_valid；这防止复位恰好发生在shadow写入与COMMIT之间时，旧COMMIT把复位默认值作为新请求应用。

COMMIT完成必须原子更新synth时钟域的参数寄存器对，再发布0723和0724。`reverb_audio_bank`现有held-bus CDC负责把一致参数对传递到FM域。本接口的确认范围仅为 **synth参数寄存器**；不宣称FM域已交付、DSP下一帧已用新参数或DAC声音已测通。将来若要确认FM域，须新增明确状态，不能扩大本版ACK的含义。

固件依次读0727、0722..0724、0727，generation不同则丢弃快照，之后重读。只有magic/ABI匹配、状态合法、范围合法的读回能发布valid；只有BUSY=0、READY=1、FAULT=0、applied sequence和本次序号相同且参数对相同，才能确认本次请求。100ms超时后不重发未知COMMIT、不再覆盖shadow；迟到ACK只能解开传输围栏，取消/过期的HTTP身份不能复活。

旧FPGA读不到RVR1、ABI不匹配、SPI读失败或状态非法时，远程混响保持禁用。固件不自动上传8192默认值，不把当前默认混响误报成远程控制可用。

本契约适用正式多引擎固件；`CONFIG_FPGA_FM_ONLY` 的FMV1验证镜像保留原固定诊断ABI，不探测或写入RVR1，也不占用其逐帧诊断读取预算。

## 设置入口与控制边界

HTTP GET/POST `/api/v2/effects/reverb`。GET仅读RAM缓存；POST使用当前v2会话、序号、context与现有同源请求头校验，发布语义事件，由voice owner再次验证，最终只有engine_link调用SPI。

POST体：`token sequence context_epoch wet_q15 damp_q15`，五个ASCII无符号十进制整数，单空格分隔，无额外字符。token/sequence/context非0；wet<=32768、damp<=28672。202只表示收到；实际生效参数和请求完成身份必须等待上述读回。

混响为跨引擎效果参数，不改变引擎选择、不发送REMT、不调用Panic/disable/RAW flush，不改变实体按键用途。新本地引擎代次或旧context失效会取消尚未派发的旧请求；已COMMIT的请求保留只读确认围栏。STOP/Off及原演奏心跳保持优先，后台每个service最多一帧SPI，只使用音乐服务之后的剩余预算。

FPGA待接入：地址解码、shadow/COMMIT mailbox、synth活动参数寄存器、coherent读回/代次、复位取消语义，以及把寄存器对接入现有wet_q15_i/damp_q15_i。本次ESP32任务不修改RTL、工程清单、约束、构建脚本或硬件。
