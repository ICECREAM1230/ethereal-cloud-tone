# UG300E manual locator

This is a project-authored locator, **not the manual text**. The official PDF and its complete Markdown conversion are external resources and are not distributed in this public package.

- Title: Arora V BSRAM & SSRAM User Guide
- Recorded edition: `UG300-1.3.6E`, dated 2025-06-27
- PDF: 80 pages; recorded SHA-256: `7b3fd3a2887a98d07075db3b812dccf903d8efe8c5dfbdb972e4067391b28fdd`
- Official source: [Gowin UG300E](https://cdn.gowinsemi.com.cn/UG300E.pdf)
- Local lookup: use a lawfully obtained matching PDF from the selected Gowin installation's `IDE/doc` or another authorized local directory. Set `GOWIN_MANUAL_DIR` to that directory; the reader accepts `UG300E.pdf` or `pdf/UG300E.pdf` below it. It does not fetch or copy documents automatically.
- Complete conversion, if independently available: `markdown/UG300E.md` below that external directory. Its recorded SHA is in [conversion.json](../conversion.json); that conversion is not provided here.

Run the page reader from this skill directory with an explicit external directory. `--verify` rejects a different PDF edition; website URLs may later serve another edition. See [lookup instructions](../../sources.md) and [manifest](../manifest.json).
