This is a project-authored locator, **not the manual text**. The official PDF and its complete Markdown conversion are external resources and are not distributed in this public package.

- Title: GW5AST series of FPGA Products Data Sheet
- Recorded edition: `DS1239-1.0.3E`, dated 2025-10-24
- PDF: 65 pages; recorded SHA-256: `6930ad832b626a1f4256a759152daf056af56abea8409e055cd7ef060a93dc68`
- Official source: [Gowin DS1239E](https://cdn.gowinsemi.com.cn/DS1239E.pdf)
- Local lookup: use a lawfully obtained matching PDF from the selected Gowin installation's `IDE/doc` or another authorized local directory. Set `GOWIN_MANUAL_DIR` to that directory; the reader accepts `DS1239E.pdf` or `pdf/DS1239E.pdf` below it. It does not fetch or copy documents automatically.
- Complete conversion, if independently available: `markdown/DS1239E.md` below that external directory. Its recorded SHA is in [conversion.json](../conversion.json); that conversion is not provided here.

Run the page reader from this skill directory with an explicit external directory. `--verify` rejects a different PDF edition; website URLs may later serve another edition. See [lookup instructions](../../sources.md) and [manifest](../manifest.json).
